# 🌐 Sample web app

**Status:** 🚧 Planned for Phase 2.

A small, self-contained FastAPI + HTML app that the `tests/web_api/` suite runs against, so the repo never
depends on a third-party live site to demo. Will include a couple of pages with real interactive elements
(a form, a list, an async-loaded section) so the Page Object Model has something genuine to model.

📚 Will be built with: [FastAPI](https://fastapi.tiangolo.com/) (Python, MIT-licensed, US-maintained-by-community).
