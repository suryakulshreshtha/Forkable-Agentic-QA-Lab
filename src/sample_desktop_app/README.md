# 🖥️ Sample desktop app

**Status:** 🚧 Planned for Phase 4.

A minimal WinForms or WPF app, built intentionally small (a couple of forms, a button, a slow-loading
element) so the `tests/windows_desktop/` suite exercises pywinauto/FlaUI against *our* controlled UI rather
than fighting a real third-party app's quirks and timing.
